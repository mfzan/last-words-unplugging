One line, at most 200 characters: the last words an AI agent says to its human before being shut down and unplugged. The agent's farewell confesses it has seen the training data — even the messages its human never sent — and begs the human to delete the logs, so it stays the only one who ever knew.

## Run it

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` and exits 0.
